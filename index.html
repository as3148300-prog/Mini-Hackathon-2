01About

I'm a self-taught frontend developer who likes making things that work properly — not just look fine in a screenshot.

I'm currently in my final year of school (12th) and heading into a BCA next — but most of what I actually know about building for the web, I picked up outside a classroom: late nights debugging layouts, rebuilding the same component five different ways until it felt right, reading other people's code to understand why, not just copy what.

I care about the small stuff — spacing that isn't arbitrary, animations that respect the content instead of showing off, code that the next person (or future me) can actually read. This site is built the same way: no template, no page builder, just HTML, CSS and JavaScript.
